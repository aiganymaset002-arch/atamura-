# ATA MURA — Digital Heritage & Innovation Platform

**Heritage creates innovation.**
Preserve the past. Research the present. Invent the future.

> История Казахстана → человек → идея → исследование → изобретение → будущее.

ATA MURA — iOS-приложение (SwiftUI), цифровая платформа Казахстана, где наследие сохраняют,
историю исследуют, знания публикуют, а идеи превращают в будущее.
Это смесь Wikipedia + Medium + цифрового музея + GitHub для изобретателей + образовательной
платформы + инклюзивной социальной сети.

Приложение сделано по образцу KKSU Online (тот же стек: SwiftUI, iOS 17, Supabase без сторонних
библиотек, Claude API), но это отдельный проект со своим Xcode-проектом и своими таблицами на сервере.

## Как открыть

1. Откройте `ATAMURA.xcodeproj` в Xcode 16 или новее.
2. Выберите схему **ATAMURA** и симулятор iPhone → **Run**.
3. Нажмите «Зарегистрироваться». Все новые аккаунты — обычные участники.

## Владелец и админ-панель

Администратор у ATA MURA один — владелец платформы. Сделать кого-то администратором из приложения
нельзя: такой кнопки нет, а сервер отклоняет любую смену роли.

- Админ-панель (щит слева вверху на главной и пункт в профиле) видит только аккаунт владельца.
- Чтобы её открыть, нужен **отдельный пароль админки** (минимум 10 символов, буквы и цифры).
  Без пароля даже аккаунт владельца работает как обычный участник.
- Админка закрывается, когда приложение уходит в фон, и через 2 часа. После 5 неверных паролей
  вход блокируется на 15 минут.
- **С сервером** (основной режим): владелец назначается и пароль задаётся только в Supabase SQL Editor —
  см. [backend/README.md](backend/README.md). Пароль хранится на сервере в виде bcrypt-хэша и
  проверяется сервером.
- **Без сервера, при запуске из Xcode** (для проверки): «Профиль → Настройки → Владелец платформы» —
  один раз задайте пароль админки. В сборке для TestFlight / App Store этого пункта нет.

Без сервера все данные хранятся на устройстве (`Documents/atamura-database.json`).
Как подключить общий сервер для всех пользователей — [backend/README.md](backend/README.md).

## Языки

Русский, English, қазақша — переключатель на первом экране и в «Профиль → Настройки».
Весь интерфейс переведён (`ATAMURA/Core/AMStrings.swift`).
Новости, выпуски журнала и курсы редакция пишет сразу на трёх языках (вкладки RU / EN / KZ в редакторе):
пользователь видит текст на своём языке, а если перевода нет — на доступном.

## Админ-панель (только для команды)

Обычные пользователи её не видят. Открывается только владельцу по паролю админки.
В «Админ-панель → Пользователи» владелец может блокировать участников.

- **Morning Dashboard** — что сделать сегодня: съёмки, публикации, сценарии, интервью, новые статьи, оплаты, проект недели.
- **ATA MURA Creator Studio**: контент-календарь (YouTube, Shorts, TikTok, Instagram, LinkedIn, ATA MURA; статусы идея → сценарий → съёмка → монтаж → готово → опубликовано; напоминания); рабочая карточка ролика (идея → цель → аудитория → название → хук 5 секунд → сценарий → кадры → вопросы → реквизит → место → участники → музыка → обложка → описание → хэштеги → ссылки → результат); **Банк идей** с AI (10 названий, структура, вопросы, Shorts); **Vlog Diary** с AI-планом выпуска недели; **People & Guests**; **Series**; **Media Library**; **Analytics** с подсказками («Истории людей набирают больше просмотров…»); **Задачи**.
- **Новости** — редактор на трёх языках, фото, видео, кнопка «Подробнее», закрепление, отложенная публикация, черновики.
- **Журнал** — «Создать выпуск»: номер, обложка, PDF, описание, дата, авторы, редколлегия, цена; после публикации выпуск появляется в ленте.
- **Курсы и заказы** — цены, скидки, промокоды, места; подтверждение оплат и возвраты.
- **Модерация** — одобрить, отклонить, на доработку; отметки «проверенный факт», «мнение автора», «гипотеза», «источник подтверждён»; жалобы; отбор историй в книгу.
- **Проекты, музей, исследования, мероприятия, партнёры и спонсоры, Marketplace, карта и энциклопедия.**

## Оплата

Сейчас покупка создаёт заказ «ожидает оплаты» (Kaspi, карта, перевод, наличные), а администратор
подтверждает оплату в «Админ-панель → Заказы и оплаты» — после этого открывается доступ.
**Перед публикацией в App Store** платные цифровые курсы, выпуски журнала и закрытые лекции нужно
продавать через встроенные покупки Apple (StoreKit), как в KKSU (репозиторий KKSU-, `KKSU/Core/KKSUAppStore.swift`):
правило App Store 3.1.1. Физические товары (наборы, билеты на офлайн-мероприятия) можно продавать как сейчас.

## AI

«Профиль → Настройки → AI ATA MURA»: ключ Claude API (хранится в Keychain) или адрес своего прокси.
Модель — `claude-opus-5-5` с адаптивным мышлением и структурированным ответом для карточки проекта.
Для App Store ключ в приложении не храните: поднимите небольшой серверный прокси и укажите его адрес.

## Структура

```
.
├── ATAMURA.xcodeproj
├── ATAMURA/
│   ├── App/        — точка входа
│   ├── Core/       — модели, хранилище, переводы, сервер Supabase, AI, тема, стартовые данные
│   ├── Features/   — экраны пользователя
│   ├── Admin/      — админ-панель и Creator Studio
│   └── Assets.xcassets
├── backend/        — schema.sql и инструкция по серверу
└── PrivacyInfo.xcprivacy
```

Стартовые исторические справки (темы, места карты, забытые идеи) краткие — их стоит проверить
и дополнить источниками. Демо-публикации помечены «(демо)» и исчезают при подключении сервера.
